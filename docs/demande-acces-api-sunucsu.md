# Demande d'accès technique SunuCSU — projet EPS1 Mbour

**Objet : Demande d'informations sur une interface officielle de vérification des cartes EDIRAMU**

Madame, Monsieur,

Dans le cadre d'un projet de digitalisation des opérations du bureau CSU de l'EPS1 Mbour, nous étudions l'intégration d'un module de lecture des QR codes des cartes EDIRAMU.

Le scanner permet déjà d'extraire le numéro d'immatriculation. Nous souhaitons savoir si SunuCSU met à la disposition des établissements de santé habilités une interface technique officielle et sécurisée permettant, après authentification et contrôle des droits, de consulter :
- le nom et les prénoms de l'assuré ;
- sa date de naissance ;
- le numéro d'immatriculation ;
- les dates de début et de fin de couverture ;
- le statut de validité de la carte à la date de consultation.

Pourriez-vous nous préciser :
1. si un service API ou un dispositif d'interconnexion existe pour cet usage ;
2. les démarches d'autorisation ou de conventionnement nécessaires pour l'EPS1 Mbour ;
3. les modalités d'authentification, les exigences de sécurité et les restrictions d'utilisation ;
4. l'existence éventuelle d'un environnement de test sans données personnelles réelles ;
5. le service ou responsable technique à contacter pour la suite.

Notre objectif est de réduire les délais de vérification des droits et les erreurs de saisie, tout en respectant les règles de confidentialité et de protection des données de santé.

Nous ne sollicitons pas de transmission de fichiers de patients ni d'identifiants d'accès personnels. Aucune intégration automatisée ne sera activée avant confirmation des autorisations requises.

Nous vous remercions par avance de votre retour.

Cordialement,

**Bureau CSU — EPS1 Mbour**

*Projet de demande à faire valider par la hiérarchie de l'établissement avant envoi.*
